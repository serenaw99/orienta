The workbench uses a separate legacy evaluator. Pages is static and does not provide the Vercel API routes. The reference agent has incomplete execution semantics. Hosted deployment versions and canonical equivalence are not established by the local Node results.

Use synthetic inputs. On hosts with the review API, requests may be logged and optionally sent for model analysis. See [limitations and data handling](docs/known-limitations.md).
